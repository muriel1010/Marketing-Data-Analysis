## Sentiment Analysis with Python

This folder contains the Python scripts used to perform sentiment analysis on customer reviews and social media feedback.

We used the VADER sentiment analysis tool from the NLTK library to classify each review into Positive, Negative, or Neutral categories.

### Files:
- `customer_reviews_enrichment.py`: The script used to clean the text and apply sentiment scoring.
- `customer_reviews_with_sentiment.csv`: The resulting dataset containing the original reviews with sentiment labels. This file was later imported into Power BI for visualization and analysis.

### Tools Used:
- Python
- pandas
- NLTK (VADER Sentiment Analyzer)
